# wallet-watchdog

Внешний «дежурный» для сервера со свиппером TRX.

- Раз в **5 минут** (GitHub Actions, публичный репозиторий — расписание бесплатно)
  пингует порт `172.86.119.96:22`.
- При **потере** сервера шлёт в Telegram: `🔴 Сервер НЕДОСТУПЕН`.
- При **возврате** шлёт: `🟢 Сервер снова в сети`.
- Сообщения приходят только на переходе состояния — спама нет.

## Настройка (один раз)

1. В репозитории → **Settings → Secrets and variables → Actions** добавьте:
   - `TG_BOT_TOKEN` — токен бота (тот же, что у свиппера);
   - `TG_CHAT_ID` — ваш Telegram ID.
2. Workflow `wallet-watchdog` включится по расписанию. Для ручной проверки —
   вкладка **Actions** → `wallet-watchdog` → **Run workflow**.
3. При первом запуске не забудьте **нажать `/start` своему боту**, чтобы его чат
   был доступен для отправки сообщений.

> Расписание (`cron: '*/5 * * * *'`) — минимум для бесплатного плана Action
> (интервалы менее 5 минут недоступны). Для более частой проверки имеет смысл
> другой бесплатный хостинг мониторинга (например, Uptime Kuma).
